ADR-013 · Memory Vault & Embeddings

Every memory is a file.
Every file has links.
Links form a graph.

No graph database. No binary blobs. A directory of plain Markdown files linked by [[wiki-links]] — that is the graph. Embeddings make it semantically searchable; spreading activation makes it associative.

What each part does
  • YAML
    Frontmatter carries all metadata — decay maths, access history, and the co_access map (Hebbian edge weights). All values are JSON literals, no YAML library needed.
  • BODY
    Free-form Markdown — the actual memory content. Human-readable in any text editor or Obsidian.
  • LINKS
    [[id|type]] wiki-links in the body create typed graph edges: related, decays_from, supersedes. This is what makes the directory a graph.
  • HEBBIAN
    co_access counts grow each time two files are recalled in the same query. The graph strengthens its own edges through use — like synaptic reinforcement.
