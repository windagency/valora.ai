# @windagency/valora-plugin-product

Product-management agent and workflow commands.

## Install

```bash
valora plugin add product
```

## What it contributes

- **1 agent**: `product-manager`.
- **6 commands**: `create-prd`, `refine-specs`, `refine-task`, `create-backlog`, `fetch-task`, `feedback`.
