# @windagency/valora-plugin-secops

Security-operations engineer agent for compliance, threat modelling, and security review tasks.

## Install

```bash
valora plugin add secops
```

## What it contributes

- **1 agent**: `secops-engineer`.

Requires `valora-core-platform` (declared via `requires`).
