# @windagency/valora-plugin-qa

QA-engineer agent and test-execution workflow commands.

## Install

```bash
valora plugin add qa
```

## What it contributes

- **1 agent**: `qa`.
- **3 commands**: `test`, `validate-coverage`, `pre-check`.

Self-contained: all commands target the bundled `qa` agent. No external `requires`.
