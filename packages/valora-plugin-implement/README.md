# @windagency/valora-plugin-implement

Specialist software-engineer agents and the `implement` command with dynamic agent selection.

## Install

```bash
valora plugin add implement
```

## What it contributes

- **4 agents**: `software-engineer-typescript` (default fallback), `software-engineer-backend`, `software-engineer-frontend`, `software-engineer-frontend-react`.
- **1 command**: `implement` — selects the most appropriate agent for a plan based on affected files and task description.
