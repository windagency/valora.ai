# @windagency/valora-plugin-quality-gate

Asserter agent and the `assert` command for codifying quality gates.

## Install

```bash
valora plugin add quality-gate
```

## What it contributes

- **1 agent**: `asserter`.
- **1 command**: `assert` — runs deterministic checks with a clear pass/fail outcome.
